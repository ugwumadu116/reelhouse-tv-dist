ON THE TV

  1. Turn on Settings → Security → Unknown sources for whichever app will open the file — the browser or the file manager.
  2. Open the TV's Browser and go to tv.rivrafrica.com/a.apk.
  3. When the download finishes, open it and approve the install.
  4. Reel House appears in your app grid.

IF THE BROWSER WON'T DOWNLOAD

Some budget TV browsers refuse to save files. Two ways round it:

  • Put the APK on a USB stick from a laptop, plug it into the TV, and open it with the file manager.
  • Or install it over the network from a computer on the same Wi-Fi, with network debugging enabled on the TV:

adb connect TV-IP-ADDRESS:5555
adb install -r ReelHouse.apk

UPDATING LATER

Install a new build straight over the old one and your resume positions and saved sources are kept. Reinstalling only fails if the APK was signed with a different key.
